# Daily Scheduler

A simple study planner for organising daily study sessions. Built with PHP, MySQL, JavaScript (AJAX) and Bootstrap.

## Features
- Add study events with a day, start time and end time
- Client-side form validation before submitting
- View upcoming events on the home page
- View past events and record sleep time

## Tech Stack
- PHP 7+ with `mysqli`
- MySQL / MariaDB
- HTML, CSS, Bootstrap 4, JavaScript

## Getting Started
1. Install XAMPP (or any Apache + PHP + MySQL setup).
2. Copy this folder into `htdocs/`.
3. Start Apache and MySQL. The `schedule` database and tables are created automatically by `db.php`.
   Optionally import `database.sql` for sample data.
4. Open `http://localhost/DailyScheduler/index.php`.
